# TripCraft – Smart Travel Planner (ReactJS SPA)

## Run locally
```
npm install
npm start          # http://localhost:3000
```

## Build
```
npm run build      # output in dist/
```

## Third-party services (no API key needed)
- Open-Meteo weather API – live weather + 5-day forecast on each destination page
- OpenStreetMap embed – location map on each destination page
